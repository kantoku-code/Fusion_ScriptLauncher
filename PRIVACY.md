# Privacy Policy for Script Launcher

Last updated: November 18, 2026

Script Launcher is an add-in for Autodesk Fusion published by kantoku. This policy describes how Script Launcher handles information when you use the add-in.

## Information handled by the add-in

Script Launcher reads the names, descriptions, folder locations, and optional icons of scripts available in your local Autodesk Fusion installation. It uses this information to display a searchable script menu and to run a script or open its folder when you choose to do so. The add-in does not send this information to the publisher or to a remote server.

Script Launcher stores your display preferences (theme, font, and transparency) and, when applicable, the palette size in a local `setting.json` file inside the ScriptLauncher add-in folder. These settings remain on your device and are not sent to the publisher.

## Third parties

Script Launcher does not use analytics, advertising services, or third-party data processing services. Scripts that you choose to run are separate programs and may have their own data practices. This policy does not cover those scripts or Autodesk Fusion itself.

## Retention and deletion

The publisher does not receive or retain data from Script Launcher. Local settings remain until you delete `setting.json` or uninstall the add-in. To remove the add-in and its settings, delete the installed ScriptLauncher folder from your Autodesk Fusion AddIns directory.

## Your choices and contact

You can stop using the add-in at any time by stopping or uninstalling it. Because the publisher does not receive data through the add-in, there is no remotely held Script Launcher data to request for deletion. For questions about this policy, use the publisher support contact listed on the Script Launcher page in the Autodesk Marketplace.
